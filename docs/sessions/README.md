# Sessions

> Session-scoped planning and execution state, written by `plan` and
> `task-executor`. Replaces the old `specs/` location — see
> [ADR-001](../registry/decisions/001-diataxis-docs-restructure.md).

Each session lives in `docs/sessions/<date>-<feature-slug>/`:

- `overview.md` — the feature spec generated by `plan`
- `tasks.md` — the execution checklist/state generated by `task-executor`

Sessions are read-once for decomposition/implementation, then folded back into
the durable Diataxis tree (`docs/how-to/`, `docs/reference/`,
`docs/explanation/`) by `doc-maintainer`'s fold-back pass. A folded session is
left in place as historical record — folding does not delete it.
