# Feature Spec: User Roles

> Generated by /compass:plan | Date: 2026-04-28 | Status: Draft

## Summary

Add a `role` field to the `User` model with values `admin | member | viewer`. Expose an admin UI at `/admin/users` to assign roles. Gate existing routes with role-based middleware.

## Implementation Order

1. Schema — add `User.role` (Prisma enum), generate migration
2. Command — `AssignRoleCommand` with validation (only admins may assign)
3. Route — `/admin/users` list + role assignment endpoint
4. UI — role badge on user list, role selector in admin panel
5. Tests — integration test for role assignment flow
