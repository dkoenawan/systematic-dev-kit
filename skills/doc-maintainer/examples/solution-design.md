## 1. System Context

### What It Does

taskflow is a lightweight web application for managing personal and team task lists. Users create projects, assign tasks to team members, set due dates, and track progress through a kanban-style board. The application sends email reminders for overdue tasks and supports CSV export.

### Who It's For

Small teams (2–20 people) who want simple shared task tracking without the overhead of enterprise project management tools.

## 3. Key Architectural Decisions

- **Single database for API and worker**: The email worker reads the `notifications` table directly rather than using a message broker — avoids operational complexity at current scale.
- **Stateless API with short-lived JWTs**: No server-side session store; JWTs expire in 15 min with a rotating refresh token cookie. Simplifies horizontal scaling.
- **Polling worker over event-driven**: Notification worker polls every 5 minutes rather than using LISTEN/NOTIFY. Simpler to debug; acceptable given latency is within spec.
- **Hard deletes only**: No `deleted_at` columns — audit requirements were out of scope at launch.
- **CSV export via streaming query**: Streams rows directly from DB to HTTP response to avoid OOM on large exports.
