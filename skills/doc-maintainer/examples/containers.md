## Primary Data Flows

1. **User authentication**: Browser → `POST /auth/login` → Nginx → API validates credentials → issues 15-min JWT + httpOnly refresh cookie → returned to browser for subsequent requests.
2. **Task creation**: Browser → `POST /api/tasks` → API persists to `tasks` table in PostgreSQL → API responds with new task → browser adds card to board.
3. **Overdue email notifications**: Worker polls `notifications` table every 5 min → finds pending rows → calls SendGrid API → marks row `sent` on success, increments `retry_count` (max 3) on failure.
4. **CSV export**: Browser → `GET /api/projects/:id/export` → API streams query results directly to HTTP response → browser triggers file download.

## Deployment Model

Containerised with Docker Compose (four services: `nginx`, `api`, `worker`, `db`). Runs on a single DigitalOcean Droplet. CI/CD via GitHub Actions: lint → test → build image → push to GHCR → deploy via SSH. TLS via Let's Encrypt managed by Nginx.
