## Overview

taskflow is a lightweight web application for managing personal and team task lists. It provides a REST API backed by a PostgreSQL database, a React single-page application for end users, and a JWT-based authentication layer. The codebase is organised into three top-level source domains: `auth`, `api`, and `ui`.
